# Статистика лазертага

Сайт: https://alanvoll.github.io/Lasertag/

Статичный сайт на GitHub Pages. Каждая игра лежит отдельным файлом в папке [`games`](games). Игроки сводятся в сезон по имени, а не по тагеру.

## Как добавить игру

1. Открыть сайт с `?admin` в адресе (https://alanvoll.github.io/Lasertag/?admin), появится вкладка «+ Добавить игру». Для остальных она скрыта. Выбрать JSON из приложения LT.
2. Проверить имена игроков (подставляются по тагерам из прошлых игр), при желании поправить выстрелы и дописать ачивки.
3. Нажать «Скачать файл игры». Скачается файл вида `2026-10-20.json`.
4. Загрузить его в папку `games` на GitHub: Add file → Upload files → Commit changes.

Через минуту-две сайт обновится сам.

Исправить игру: открыть игру по адресу с `?admin`, нажать «Изменить», скачать файл и загрузить его с тем же именем, он заменит старый. Удалить игру: удалить её файл из `games`.

## Устройство

- `index.html`, `style.css`, `app.js` — сам сайт, без сборки.
- `games/*.json` — игры.
- `.github/workflows/pages.yml` — при каждом пуше в `main` собирает список игр `games/index.json` и публикует сайт.
